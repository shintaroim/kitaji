# きたじまのき（きたじー）Webサイト プロトタイプ

元公立高校教員25年・7,200人を育てた「きたじまのき（きたじー）」公式Webサイト＆ランディングページのプロトタイプです。

## 🌐 公開URL (GitHub Pages)
👉 **[https://shintaroim.github.io/kitaji/](https://shintaroim.github.io/kitaji/)**

---

## 📱 画面構成

| 画面名 | ファイル | 説明 |
| :--- | :--- | :--- |
| **【案1】法人向けコーポレートサイト** | [`index.html`](index.html) | 次世代リーダー育成・組織開発・若手自走化研修の総合コーポレートサイト |
| **【案2】教員セカンドキャリア塾 LP** | [`teacher_lp.html`](teacher_lp.html) | 教員のセカンドキャリア・独立支援特化型ランディングページ（最注目） |
| **【案3】統合ポータル画面** | [`portal.html`](portal.html) | 法人向け・教員向け・個人向け・動画コンテンツを網羅した総合案内ポータル |
| **【資料】共有資料ポータル** | [`materials/`](materials/) | クライアント向け総合提案書PDF・各種提案資料のダウンロード一覧 |

---

## 🛠 技術スタック
- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (BIZ UDPGothic, Inter, Noto Sans JP)
- レスポンシブデザイン（スマートフォン・タブレット・PC対応）
